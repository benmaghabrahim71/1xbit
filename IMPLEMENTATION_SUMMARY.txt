     └─ PostgreSQL via Neon

================================================================================
HOW IT WORKS
================================================================================

LOCAL DEVELOPMENT (npm run dev):
  Request → Express Server → Routes → Database
           ↓
        Static files from root directory

VERCEL PRODUCTION:
  Request → Vercel Router (vercel.json)
           ├─ /api/* → Serverless Function → Express.js → Routes
           ├─ /metrics → Serverless Function
           └─ /* → Static files from /public

================================================================================
DEPLOYMENT PATHS
================================================================================

PATH 1 - GITHUB + VERCEL DASHBOARD (Recommended)
  1. Push code to GitHub
  2. Go to vercel.com
  3. Create New Project
  4. Import from GitHub repository
  5. Add environment variables
  6. Deploy (automatic)

PATH 2 - VERCEL CLI
  1. npm install -g vercel
  2. vercel link
  3. vercel env pull .env.local
  4. vercel (to deploy)

PATH 3 - LOCAL TESTING FIRST (Safest)
  1. cp .env.example .env.local
  2. Edit .env.local with real values
  3. npm install && npm run dev
  4. Test at http://localhost:3001
  5. Then deploy to Vercel
